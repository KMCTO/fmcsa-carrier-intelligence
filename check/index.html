Run a carrier check

Last updated: October 17, 2026.

Have an API key? Enter it here, give a USDOT or MC number, and get the result in your browser. No code needed. No key yet? Request a free evaluation key, which comes with $5 of credit.

Which check?

You are charged only when the check returns records. A number that does not exist costs nothing.

About this page

  • Your key goes only to our API, over HTTPS, from your browser. This page has no analytics and sets no cookies. The key is not stored unless you tick the box, and then only for this tab.
  • Each result states the date its records are current as of. It is not live. For about 72% of Active-authority carriers, authority and insurance-on-file fields describe 2026-05-14, because FMCSA stopped updating its legacy archive on that date. Results say so when it applies.
  • A result is a record of what public data showed, not a score, a recommendation or legal advice, and not a statement that choosing a carrier was reasonable.
  • To keep a selection record as evidence, use Download record. The hash covers the exact record we issued, so a printout or screenshot cannot be verified later; the downloaded file can, with the free /verify/<hash> link.

Prefer code? See the API documentation. Prices are on the pricing page.
